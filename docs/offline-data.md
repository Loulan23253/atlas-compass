# 离线数据与模板清单

基线核查日期：2026-10-18。`npm run test:offline` 使用生产构建配置检查实际依赖，并模拟缺少数据目录、文件损坏、读盘失败及有效本地覆盖四种情况。

## 发布包里有什么

安装 `main.js`、`manifest.json`、`styles.css` 即可使用基础地图、轨迹导入、城市匹配与手记。以下数据以文本形式内置于 `main.js`，需要时才解析和建立索引；文本仍会增加插件加载体积。

| 数据 | 当前源数据规模 | 打包情况 |
| --- | --- | --- |
| 世界城市库 | 34,149 条地名记录 | 完整内置 |
| 国家/地区轮廓 | 原始 Natural Earth 文件 177 个要素 | 内置；显示时统一替换中国轮廓，要素数不等于国家数 |
| 全球省/州级边界 | 原始简化数据 4,596 个要素 | 简化版内置，高清文件可选 |
| 中国省级边界 | 34 个行政区及独立边界线符号 | 内置，含台湾；边界符号不计为陆地 |
| 中国市级数据 | 原始文件 371 个要素 | 简化版内置；其中省级轮廓按真实层级展示，并非 371 个城市 |
| 日本市町村 | 1,807 个要素 | 简化版内置，高清文件可选 |
| 中国陆地格点 | 499,757 个 geohash5 格 | 完整内置 |
| 机场 | 131 条记录 | 随代码内置 |

`data/admin1.geojson`、中日未简化市级边界等高清文件不打包。有效的本地数据优先；同一数据集所选精度不可用时尝试另一精度，再尝试内置基线。没有内置基线的扩展国家市级数据仍需本地文件。

中国全国轮廓、省级轮廓与边界符号由 `ChinaBoundary.ts` 统一内置，更新这些源文件需要重新构建，以保证地图与覆盖率报告一致。

## 用户记录放在哪里

- 城市和地点：配置的旅行目录下的 Markdown 笔记及属性。
- GPS：旅行目录下 `轨迹/日期.geojson`，包括路程、交通段、停留、海拔与已覆盖格点等。
- 旅程、年度回顾、照片足迹、覆盖率报告：旅行目录下的 Markdown/SVG。
- 插件设置和导入历史：插件自己的 `data.json`。

这些个人记录不属于构建输入。换设备时除插件外，还应同步笔记库与需要保留的插件配置。

## 模板与更新方式

| 模板 | 现有行为 |
| --- | --- |
| 城市手记 | 动态到访日期、片刻、照片、收藏、随手记 |
| 地点收藏 | 动态到访日期、停留理由、照片、到达方式与时段 |
| 国家索引 | `atlas-country` 动态汇总已建档的到访城市、地点和未到访收藏 |
| 旅程手记 | 真实日期、地点、GPS 摘要、日记链接、独立个人区 |
| 年度回顾 | 年度日历、同期对比、首次/再次到访、月度记录、旅程索引、独立个人区 |
| 照片足迹 | JPEG EXIF 时间与位置、照片预览、地点索引、独立个人区 |
| 覆盖率报告 | 陆地覆盖比例、月度增长及含南海附图的中国地图 |

模板代码随插件构建。已有笔记不会因构建而自动改写。城市旧模板运行“升级城市笔记为旅行手记”可补足足迹和照片区；自定义内容、已有照片栏目保持原样。生成型报告只更新仍通过内容校验的自动区，个人区保留；手改过自动区时另存新版。

## 仍有边界

- 地名库是城市定位库，不包含每座城市的景点、美食、简介或自动游记素材。
- 国家/地区名称目前以笔记实际字段匹配；不同语言别名尚未统一到稳定 ID。
- 照片识别目前支持 JPEG EXIF，中国、日本以外的照片尚未接入世界城市兜底；HEIC 不支持。照片格点不计入 GPS 覆盖率。
- 城市/地点自动查坐标使用配置的在线地理编码服务，会发送查询的地点及国家名称。地图、GPS 处理与报告生成可离线完成。
- 发布脚本尚未加入持续集成；发布前应运行零警告 lint、类型检查、笔记、地图、离线数据及发布包一致性测试。

## 发布包精简（2026-10-20）

同日模板更新：城市/地点增加同行与重访线索，国家增加路线与准备提示，旅程/年度/照片个人区采用折叠写作提示。城市与国家动态区可跳转到对应到访日期的已有报告；年度自动区新增季度书签。命令“丰富现有旅行手记栏目”仅补缺失的个人栏目，不替换旧文字或自动报告内容。

构建阶段裁剪地图中未消费的属性并去掉 JSON 空白；原始 `data/` 文件和全部几何坐标保持不变。`main.js` 从 31,279,104 字节降为 19,995,660 字节，减少 36.1%（约 29.83 MiB → 19.07 MiB）。

`npm run test:bundle` 分别构建未精简与精简版本，比较实际加载出的国家、省级、中日市级及中国全国、省级、边界符号完整数据，确认坐标、名称、行政代码、父级、标签中心一致。新增地图字段时需同步更新构建保留字段。
